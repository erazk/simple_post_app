## ▶️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Flutter SDK
- Dart SDK
- Android Studio
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/erazk/simple_post_app.git
```

Go to the project folder:

```bash
cd simple_post_app
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
